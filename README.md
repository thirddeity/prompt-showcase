# prompt-showcase

จัดทำโดย: พงศ์อมร วงศ์เฉลิมทานต์  
รหัสนักศึกษา: 2610711302015
เว็บพอร์ตโฟลิโอส่ง อ.อภิมุข ม่วงเกษม  
หัวข้อหลัก: เปรียบเทียบการใช้งาน Prompt Engineering

ทำเพื่อรวบรวมงาน 6 ชิ้นไว้หน้าเดียว อ่านง่าย และโชว์ว่า zero-shot กับ few-shot ต่างกันยังไง ไม่ได้ทำมาขายของหรือโฆษณา AI

## ข้างในมีอะไร

1. Canva — สร้างภาพด้วย AI
2. Desmos — กราฟคณิตศาสตร์
3. Mermaid — ไดอะแกรมจากโค้ด
4. LaTeX — บทความ/เอกสาร
5. NotebookLM — สไลด์สรุปงาน
6. PDF Slide - slides งานจริง

แต่ละส่วนเรียงตามโจทย์: prompt แรก → ผล → เพิ่มรายละเอียด → ผลใหม่ → สะท้อนสิ่งที่เรียนรู้

## รันยังไง

```bash
pnpm install   # หรือ npm install
pnpm dev       # หรือ npm run dev
```
